Pertanyaan yang Sering Diajukan (FAQ)

1. Bagaimana jika saya lupa kata sandi?

Silakan klik tombol "Hubungi Admin" di menu bawah untuk meminta pengaturan ulang (*reset*) kata sandi kepada petugas IT/HRD perusahaan.

2. Mengapa muncul tulisan "Username tidak valid"?

Pastikan ejaan nama pengguna Anda sudah benar, tidak menggunakan huruf besar jika terdaftar sebagai huruf kecil, dan tidak mengandung spasi.

3. Apakah aplikasi ini aman digunakan?

Ya. Sistem menggunakan protokol keamanan enkripsi kontemporer bersertifikat untuk memastikan integritas data pribadi dan riwayat kerja Anda tidak dapat diakses pihak luar.
